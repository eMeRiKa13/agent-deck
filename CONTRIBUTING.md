# Contributing

Agent Deck is published as a source showcase. The project does not currently
accept unsolicited feature requests, bug reports, or pull requests, and GitHub
Issues and Discussions are disabled.

If you discover a security issue, follow the private process in
[`SECURITY.md`](./SECURITY.md). Do not open a public pull request or disclose the
issue publicly.

Maintainer changes must pass the commands documented in the
[`README`](./README.md#develop-and-verify) before they are merged.
