# Agent Deck

Agent Deck is a read-only macOS dashboard for monitoring Codex, Claude, and Cursor sessions and usage from one window.

![Agent Deck running at 2560 × 720](./agent-deck-2560x720.png)

## Features

- Aggregates recent Codex, Claude, and Cursor conversations.
- Displays available quotas, reset windows, and usage metrics.
- Refreshes local data automatically.
- Provides a touch-friendly interface optimized for a 2560 × 720 ultrawide display.
- Keeps the usage column visible on compact layouts and opens session details in a side panel.
- Supports French and English.
- Remains strictly read-only: it cannot create, resume, stop, or modify a session.

## Languages

On first launch, Agent Deck uses French when the system language starts with `fr`. It uses English for every other system language. The `FR` / `EN` selector in the top bar updates the interface, dates, and numbers immediately. Agent Deck stores your manual selection locally and uses it on subsequent launches.

Agent Deck never translates titles or messages from real conversations. It only translates labels generated by the application. The demo data shown by `pnpm dev` includes both French and English content.

## Data sources

Agent Deck does not require its own remote server. Its Rust adapters read data already stored on your Mac:

- **Codex:** threads from `~/.codex/state_5.sqlite`, JSONL rollouts, and quotas exposed by the `codex app-server` bundled with the app.
- **Claude:** conversations from `~/.claude/projects`, Claude Desktop metadata, local usage history, and the Anthropic OAuth usage endpoint when compatible credentials are available.
- **Cursor:** conversations from `state.vscdb` and the Cursor usage summary retrieved with the local session.

Agent Deck opens databases in read-only mode. Tokens remain in the Rust backend and are never exposed to the Vue interface.

> Local application formats are not stable public APIs. Updates to Codex, Claude, or Cursor may require changes to the adapters.

## Tech stack

- Tauri 2 and Rust
- Vue 3, TypeScript, and Vue I18n 11
- Vite 8 and Tailwind CSS 4
- VueUse, Lucide, and Vitest

## Prerequisites

- macOS
- Node.js 22 or later
- pnpm 10
- A stable Rust toolchain
- Codex, Claude, and/or Cursor installed and used at least once

## Run the desktop app

```bash
git clone https://github.com/eMeRiKa13/agent-deck.git
cd agent-deck
pnpm install
pnpm dev:desktop
```

Tauri starts Vite at `http://127.0.0.1:1421` and opens the native macOS window.

To work on the interface in a browser with demo data, run:

```bash
pnpm dev
```

## Verify the project

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm build:desktop
```

Run the Rust unit tests directly with:

```bash
PATH="$HOME/.cargo/bin:$PATH" cargo test --manifest-path src-tauri/Cargo.toml
```

Smoke tests that depend on locally installed application data are ignored by default. Run them with:

```bash
PATH="$HOME/.cargo/bin:$PATH" cargo test --manifest-path src-tauri/Cargo.toml -- --ignored
```

## Project structure

```text
src/                    Vue interface and demo data
src/components/         Dashboard components
src/composables/        Polling and application state
src-tauri/src/providers Codex, Claude, and Cursor adapters
src-tauri/              Tauri configuration and Rust backend
```

## Privacy

Agent Deck runs locally. It does not send conversations to a third-party service or expose credentials collected by the Rust adapters to the frontend.
